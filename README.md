## 📌 Overview

The **Event Management System** is a web application built with **Python, HTML, CSS, and MySQL**. It helps users create, manage, and register for different types of events, with all data stored in a MySQL database.

**Suitable for:**

| Event Type | Examples |
|:--|:--|
| 🎭 Cultural | College cultural fests |
| 💻 Technical | Technical symposiums |
| 💍 Social | Wedding events |

<br>

## ✨ Features

| | Feature | Description |
|:--:|:--|:--|
| 🔐 | **User Authentication** | Secure sign-up and login for users |
| 📅 | **Event Creation & Management** | Create events and keep their details organized |
| 📝 | **Event Registration** | Register for events directly from the platform |
| 👀 | **View Available Events** | Browse all events currently open |
| 📋 | **Registration Management** | Track and manage registrations |
