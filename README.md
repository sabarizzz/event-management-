## 🎟️ EVENT MANAGEMENT SYSTEM

A **web-based Event Management System** for **creating, managing, and registering for events** using **Python, HTML, CSS, and MySQL**.

This system helps users create, manage, and register for different types of events such as:

- 🎭 **College cultural fests**
- 💻 **Technical symposiums**
- 💍 **Wedding events**
